# FassoliDev - Institutional Business Website

A modern, responsive institutional website for FassoliDev, a professional software development company.

## Features

- 🎨 **Modern Design**: Clean and professional interface with smooth animations
- 📱 **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- ⚡ **Fast & Lightweight**: Built with vanilla HTML, CSS, and JavaScript
- 🎯 **SEO Optimized**: Proper meta tags and semantic HTML structure
- 🧭 **Easy Navigation**: Smooth scrolling and intuitive menu
- 📧 **Contact Form**: Interactive contact form for client inquiries

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About Section**: Company information and key statistics
3. **Services Section**: Showcase of core services offered
4. **Portfolio Section**: Display of completed projects
5. **Contact Section**: Contact information and inquiry form
6. **Footer**: Quick links and social media integration

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/SamuelSaidDev/fassolidev-website.git
```

2. Navigate to the project directory:
```bash
cd fassolidev-website
```

3. Open `index.html` in your web browser or serve it using a local server.

### Using a Local Server

**Using Python:**
```bash
python -m http.server 8000
```

**Using Node.js (http-server):**
```bash
npx http-server
```

Then open `http://localhost:8000` in your browser.

## Customization

### Updating Content

- **Company Information**: Edit the text content in `index.html`
- **Colors & Styling**: Modify CSS variables in `styles.css` under `:root`
- **Services**: Add/remove service cards in the services section
- **Portfolio**: Update project showcases in the portfolio section

### Color Scheme

The website uses CSS custom properties for easy theme customization:

```css
:root {
    --primary-color: #4A90E2;
    --secondary-color: #667eea;
    --accent-color: #764ba2;
    --text-dark: #2C3E50;
    --text-light: #6C757D;
}
```
